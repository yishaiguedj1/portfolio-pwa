# תיק ההשקעות — האפליקציה

אפליקציה שמציגה את תיק ההשקעות שלך בצורה נוחה ויפה.
עובדת בטלפון, בטאבלט ובמחשב. מתקינים אותה מהדפדפן — בלי חנות אפליקציות.

## קישורים חשובים

- **האפליקציה עצמה (האתר החי):** https://yishaiguedj1.github.io/portfolio-pwa/
- **המקום שבו נשמר הקוד:** https://github.com/yishaiguedj1/portfolio-pwa

## מה יש בפנים

- **סקירה** — כמה שווה התיק עכשיו, כמה הרווחת או הפסדת, ומעבר בין דולר לשקל.
- **מניות** — 9 המניות שלך. לוחצים על שורה והיא נפתחת: מחיר עדכני, שינוי מהיום, רווח מול מחיר הקנייה, וגרף שאפשר לשנות לו טווח (יום, שבוע, חודש, שנה...).
- **הפקדות** — כל 48 ההפקדות שעשית, כל אחת עם התאריך המדויק שלה.
- **פנסיה** — קרן הפנסיה וקרן ההשתלמות.
- **ביצועי התיק לאורך זמן** — הדמיה של האחזקות הנוכחיות מול מדד S&P 500 (שנה / 3 / 5 שנים / מקסימום).
- **הגדרות** — החשבון שלי (התחברות עם Google), מפתח הנתונים, מזומן בדולרים ובשקלים, שווי קרנות, גיבוי (ייצוא/ייבוא קובץ) ואיפוס לנתוני הגיליון.
- **עריכת נתונים** — בכל לשונית יש כפתור "✏️ עריכה" (כבוי כברירת מחדל): הוספה, עריכה ומחיקה של מניות, הפקדות והפקדות פנסיה. מחיקה תמיד מבקשת אישור.

## איך מתקינים על הטלפון

- **אנדרואיד:** פותחים את הקישור בדפדפן כרום ← תפריט (שלוש נקודות) ← "התקנת האפליקציה".
- **אייפון:** פותחים את הקישור בדפדפן ספארי ← כפתור השיתוף ← "הוספה למסך הבית".

## איך מעדכנים את האפליקציה

פשוט מבקשים מ־Ember מה לשנות (למשל: "תוסיף מניה", "תשנה צבע").
הוא מעדכן את הקוד, והאתר מתעדכן לבד תוך דקה־שתיים. בפתיחה הבאה כבר רואים את הגרסה החדשה.

## חשבונות וסנכרון ענן

- מתחברים עם חשבון Google (כפתור אחד) — כל אחד רואה רק את התיק האישי שלו.
- הנתונים נשמרים אוטומטית בענן (Firebase, חינם) ומסונכרנים בין מכשירים — בלי ייצוא וייבוא.
- אפשר גם להמשיך בלי חשבון — אז הכל נשמר בטלפון כמו קודם.
- הערה לבעל הפרויקט: החיבור לענן דורש פרויקט Firebase פעם אחת (5 דקות) — ראה יומן-עבודה.

## דברים שכדאי לדעת

- המחירים מתעדכנים מהאינטרנט בכל פתיחה, עם דיליי קצר של כ־15 דקות (לא בכל שנייה).
- המחירים החיים: CNBC, עם גיבוי אוטומטי מ־Yahoo.
- בלילה, כשאין מסחר, מוצג מחיר הסגירה האחרון.
- בלי אינטרנט מוצגים הנתונים האחרונים שנשמרו, עם הערה ברורה.
- הגרפים וההיסטוריה: Twelve Data (כולל מסחר מורחב — לפני הפתיחה ואחרי הסגירה), עם גיבוי מ־Yahoo ו־Stooq.

## הפעלת הגרפים (צעד אחד קטן)

הגרפים צריכים מפתח נתונים חינמי מ־Twelve Data:
1. נרשמים בחינם (דקה, בלי כרטיס אשראי): https://twelvedata.com/pricing
2. מעתיקים את המפתח האישי מהאתר שלהם.
3. פותחים את האפליקציה ← לשונית "מניות" ← מדביקים את המפתח בכרטיס "הפעלת הגרפים" ← שמור.

המפתח נשמר רק בטלפון שלך, לא באתר ולא בקוד — אז אפשר לשתף את האפליקציה בלי חשש.
כל מי שמקבל את הקישור עושה את אותה הרשמה חינמית פעם אחת.
