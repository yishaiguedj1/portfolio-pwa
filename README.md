# תיק ההשקעות — אפליקציית Web (PWA)

דשבורד תיק ההשקעות של ישי כאפליקציית ווב עצמאית, ניתנת להתקנה על כל מכשיר (אנדרואיד / אייפון / מחשב) — בלי חנות אפליקציות ובלי APK.

## מה יש באפליקציה

- **סקירה** — שווי תיק המניות, רווח/הפסד ותשואה מול הפקדות נטו (₪187,319), מעבר $/₪, גרף פאי של חלוקת התיק.
- **מניות** — 9 פוזיציות, כל שורה נפתחת: מחיר חי, שינוי יומי, שווי, רווח/הפסד מול מחיר קנייה, משקל, מחיר ATH ואחוז מהשיא, וגרף עם טווחים (יום / שבוע / חודש / YTD / שנה / 5 שנים / מקסימום) כולל מצב מדידה בין שתי נקודות (עובד עם אצבע ועם עכבר).
- **הפקדות** — כל 48 ההפקדות עם תאריך מדויק, בלשונית נפרדת ונקייה.
- **פנסיה** — מנורה, Fnx ומיטב + הפקדות פנסיה.
- המחירים נמשכים בכל פתיחה ממקור חינמי (Stooq, דיליי ~15 דקות). אין כיסוי למסחר לילי (overnight) — מצוין בשקיפות בממשק. בלי חיבור אינטרנט מוצגים הנתונים האחרונים השמורים, עם סימון ברור.

## קבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | מבנה האפליקציה (עברית, RTL) |
| `styles.css` | עיצוב Material Design 3 |
| `app.js` | כל הלוגיקה: נתונים, מחירים חיים, גרפים |
| `manifest.webmanifest` | הגדרות PWA (שם, צבעים, אייקונים) |
| `sw.js` | Service Worker — עבודה אופליין ועדכוני גרסה |
| קבצי האייקונים (icon-192.png, icon-512.png) | אייקונים 192 ו־512 (להוסיף בנפרד) |

אין תלויות חיצוניות בזמן ריצה — כל הגרפים מצוירים ידנית ב־canvas, הפונטים מערכתיים.

## תצוגה מקדימה מקומית

```bash
cd ~/workspace/pwa-portfolio
python3 -m http.server 8000
```

ואז פותחים בדפדפן: `http://localhost:8000`

> חובה להגיש דרך שרת מקומי (לא `file://`) כדי שה־Service Worker והמניפסט יעבדו. `localhost` נחשב secure context, כך שאפשר לבדוק התקנה.

## פרסום ב־GitHub Pages (בחינם, מהטלפון)

1. יוצרים חשבון GitHub (חינם) וריפו חדש, למשל `portfolio-pwa`.
2. מעלים את כל הקבצים מהתיקייה `pwa-portfolio` לריפו (אפשר מהדפדפן בטלפון: לשונית הקבצים ← Add file ← Upload files).
3. בהגדרות הריפו ← **Pages** ← תחת Build and deployment בוחרים **Deploy from a branch** ← branch `main` ← תיקייה `/ (root)` ← Save.
4. אחרי כדקה מתקבל לינק ציבורי מסוג `https://<user>.github.io/portfolio-pwa/`.

## התקנה על מכשיר

- **אנדרואיד (כרום):** פותחים את הלינק ← תפריט ⋮ ← **"התקנת האפליקציה"** (או "הוספה למסך הבית").
- **אייפון (ספארי):** פותחים את הלינק ← שיתוף ← **Add to Home Screen**.
- **מחשב:** אייקון ההתקנה בשורת הכתובת.

## עדכונים

כל שינוי בקבצים (עיצוב, פיצ׳רים) שמעלים לריפו מתפרסם אוטומטית — המשתמשים מקבלים את הגרסה החדשה בפתיחה הבאה (ה־Service Worker מנקה מטמון ישן לפי `CACHE_NAME` ב־`sw.js`; לזכור להקפיץ גרסה בשינוי).

## מגבלות ידועות

- המחירים החינמיים בדיליי של כ־15 דקות, לא זמן־אמת מלא.
- אין נתוני מסחר לילי (overnight) — מחוץ לשעות המסחר מוצג מחיר הסגירה האחרון.
- סכום (כמות × מחיר קנייה ממוצע) גבוה בכ־₪10.7K מסך ההפקדות — מפורט בהערת השקיפות באפליקציה; כדאי לוודא מול הגיליון.
