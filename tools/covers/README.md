# כריכות למכתבי באפט (האקדמיה)

כריכה בעברית לכל מכתב: סגול `#6951A5`, "ברקשייר האת'וויי" / "מכתב לבעלי המניות" / השנה / "וורן א. באפט",
ודיוקן חריטה לבן. העיצוב הותאם בהשראת כריכה מסחרית — **בלי** הלוגו של ההוצאה, חותם "60 years" או האיור שלהם (אושר ע"י המשתמש, 04/10/2026).

**תמונות לא נכנסות לריפו** (ציבורי): תמונת המקור של באפט שהמשתמש צירף היא צילום מקצועי עם זכויות יוצרים —
הכריכות לשימוש אישי בלבד. בסשן חדש: לבקש מהמשתמש לצרף שוב את התמונה (559×315, באפט מחייך, רקע אפור).

## שלבים
1. `python3 prep.py <dir> <photo.jpg>` → `crop2.jpg` + `mask2.png`
2. `python3 engrave.py <dir>` → `portrait4.png` (קווי מתאר, תווי פנים, הצללה מקבילית, קווצות שיער LIC, קמטים)
3. להעתיק `cover.html` + `NotoSansHebrew-VF.woff2` (מ־`fonts/`) לאותה תיקייה, שרת מקומי על 8790,
   `node shoot.js <dir>` → `cover-<שנה>.png` (1574×2000). שנים: לשנות את הרשימה ב־shoot.js.

## האחדת פרטי הספר (בוצע 04/10/2026, v314)
`build.py <תיקיית עבודה>` — לכל מכתב: OPF אחיד + `images/cover.jpg` (פריט מניפסט עם `properties="cover-image"` + `<meta name="cover">`).
**בלי** עמוד כריכה בסדר הקריאה (הוא היה מזיז את כל מיקומי ה־CFI — התקדמות/הדגשות), **בלי** לשנות `dc:identifier`, הטקסט או הפרקים.
השדות: כותר `מכתב באפט ‹שנה›` + כותר משנה, כותב `וורן א. באפט` (aut, file-as `באפט, וורן א.`, באנגלית Warren E. Buffett),
1965–1969 — החותמים בפועל (צ'ייס) כ־`dc:contributor` בתפקיד `sgn`, הוצאה, תאריך = השנה שבשם הקובץ (החלטת המשתמש),
נושאים, תיאור, מקור, זכויות, סדרה (`belongs-to-collection` + `calibre:series`/`series_index` = השנה).
`shoot.js <dir> <list.txt>` — כריכה לכל שנה (2025: "מכתב חג ההודיה" דרך `?t2=`).

**ההעלאה לדרייב:** מחבר ה־Drive לא מחליף תוכן של קובץ, ודרך השרתון (הרשאת עורך זמנית) נחסמה ע"י מנגנון ההרשאות של הסשן.
בפועל: zip למשתמש → העלאה לתיקייה חדשה `Warren E. Buffett` תחת תיקיית הספרייה (באנדרואיד: Chrome במצב "אתר למחשב").
הספרייה מוגנת מפני מחיקה כשמכתב עובר לקובץ אחר עם אותו מזהה (v314).
