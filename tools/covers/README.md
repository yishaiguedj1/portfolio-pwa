# כריכות למכתבי באפט (האקדמיה)

כריכה בעברית לכל מכתב: סגול `#6951A5`, "ברקשייר האת'וויי" / "מכתב לבעלי המניות" / השנה / "וורן א. באפט",
ודיוקן חריטה לבן. העיצוב הותאם בהשראת כריכה מסחרית — **בלי** הלוגו של ההוצאה, חותם "60 years" או האיור שלהם (אושר ע"י המשתמש, 04/10/2026).

**תמונות לא נכנסות לריפו** (ציבורי): תמונת המקור של באפט שהמשתמש צירף היא צילום מקצועי עם זכויות יוצרים —
הכריכות לשימוש אישי בלבד. בסשן חדש: לבקש מהמשתמש לצרף שוב את התמונה (559×315, באפט מחייך, רקע אפור).

## שלבים
1. `python3 prep.py <dir> <photo.jpg>` → `crop2.jpg` + `mask2.png`
2. `python3 engrave.py <dir>` → `portrait4.png` (קווי מתאר, תווי פנים, הצללה מקבילית, קווצות שיער LIC, קמטים)
3. להעתיק `cover.html` + `NotoSansHebrew-VF.woff2` (מ־`fonts/`) לאותה תיקייה, שרת מקומי על 8790,
   `node shoot.js <dir>` → `cover-<שנה>.png` (1574×2000). שנים: לשנות את הרשימה ב־shoot.js.

## השלב הבא (תוכנית)
בסשן עם מחבר Google Drive: לכל EPUB בתיקיית הספרייה — לאחד את `dc:creator` לשם אחד לכל כותב,
ולהוסיף את הכריכה (פריט ב־manifest עם `properties="cover-image"` + `<meta name="cover">`), **בלי לשנות `dc:identifier`**.
אחר כך: הספרייה באפליקציה תציג את הכריכה מהקובץ (היום היא מציירת כריכה טיפוגרפית).
