# הלוגו של THE SNOWBALL

| קובץ | מה זה |
|---|---|
| `snowball-logo.png` | **המאסטר** — 1024×1024, רקע שקוף, הלוגו ממורכז עם 2% שוליים. מכאן מייצרים כל גודל. |
| `snowball-logo-512.png`, `snowball-logo-256.png` | אותו דבר בגדלים קטנים. |

`logo-header.png` (כותרת), `icon-192.png` / `icon-512.png` / `icon-maskable-512.png` (PWA, גם מסך הכניסה), `apple-touch-icon.png`, `favicon-48.png`,
ובאנדרואיד: `mipmap-*/ic_launcher*.png`, `drawable-nodpi/widget_logo.png` (רקע האייקון `icon_bg` שקוף).
