# מנתח החברות וגרף הנרות בזכוכית — התוכנית (17/11/2026)

**הבקשה**: להתאים את מסך הניתוח (`analysis.js`/`analysis.css`) ואת גרף הנרות (`chart.js`/`chart.css`) לשפת העיצוב של Invest מ־2.166.0 (`docs/invest-design-plan.md`). **המבנה זהה**: אותם מסכים, לשוניות, כלים ומספרים. ⛔ לא נוגעים בחישובים, בנתונים או בלוגיקה של הגרף. על אלה רצות בדיקות עומק בסשנים אחרים (`docs/fund-deep-audit.md`, `docs/chart-deep-audit.md`).

## העקרונות (כמו ב־Invest)
- זכוכית רק על מה שצף: כפתורי ההדר, "חזור", ✕, צ׳יפים, בוררי האינטרוול והטווח, סרגל הכלים והגיליונות. התוכן (כרטיסים, אריחים, טבלאות) במילוי רך בלי טשטוש.
- בוררים: מסילה עדינה וידית לבנה (אפורה בכהה). הירוק נשמר לנתונים ולפעולה.
- מספרים: גופן מעוגל וספרות ברוחב אחיד. המחיר בצבע הטקסט, והשינוי בגלולה צבעונית.
- לחיצה גמישה בקפיץ (`--lg-spring`).

## איך זה ייבנה
- **CSS**: באותה שכבה (`@layer invglass`, עם `!important`), בקובץ צמוד `invest-glass-ac.css` או בהמשך `invest-glass.css`. נטען רק ב־`index.html`. הבוררים מוגבלים ל־`html .an-root` / `html .kc-root` / `html .an-sheet`. הבדיקה של `invest-glass.test.js` תורחב בהתאם.
- **הקנבס של הגרף** מצויר ב־JS (`palette()` ב־`chart.js`), ולכן CSS לבדו לא משנה אותו. השינוי: `palette()` קורא טוקנים (`--kc-cv-grid`/`axis`/`text`/`label`/`font`/`vol`) עם ברירות המחדל של היום, ונפח ורדיוס התווית לוקחים אותם משם. אין שינוי בנתונים, בנרות, ב־`--gain`/`--loss` ובפלטות "קלאסי" ו"שחור־לבן". ממצא אגבי: `font:` של הפלטה נמצא היום בתוך הערה (שורת `glass:`), ולכן הצירים בגופן ברירת המחדל של הספרייה.

## התצוגה המקדימה
Artifact עם `index.html` האמיתי בתוך iframe, בלי CSP ובלי frame-busting. fetch מדומה: `op:'fund'`/`'macro'` מ־`tests/fixtures/qa` (ציבורי), נרות סינתטיים ותיק הדמו. השינויים בשכבה `html.ap-*`, ולכל שינוי יש "הצג בטלפון" ואשר/אולי/דחה (db של ה־Artifact). שינויי הקנבס מוצגים דרך עותק של `chart.js` שקורא `--kcv-*` (רק בתצוגה). 15 השינויים: ap-anmat, annav, anseg, anrng, annum, ankeys, anlist, antbl, ansheet, kcpal, kctop, kcbar, kcsheet, kctip, press.
