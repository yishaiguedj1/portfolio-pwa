## 5. פרוטוקול ההשוואה (`compare.py`)
- **מפתח**: תוך־יומי — תחילת הנר ב־UTC; יומי — התאריך באזור הזמן של הבורסה (קריפטו — UTC); שבועי — שבוע ISO; חודשי — YYYY-MM; 3M/6M/12M — חודש תחילת התקופה.
- **רשת צפויה (ת־גרף)**: ארה"ב — עוגן 9:30 (במורחב 4:00), כל מרווח מהעוגן (45 דק׳ = 9:30, 10:15…; 4 שעות = 9:30, 13:30); קריפטו — 00:00 UTC; מט"ח — 17:00 ET; חוזים — 18:00 ET; ת"א — הנר הראשון של היום. ימים מקוצרים — הסשן עד 13:00 (מורחב עד 17:00).
- **סובלנות**: מניות — טיק (0.01$ מעל דולר; מתחת 0.0001), עם סימון נפרד של התאמה בחצי טיק; קריפטו — 0.3% פתיחה/סגירה, 0.6% גבוה/נמוך (מדד מצרפי מול בורסה); מט"ח — 0.05%. נפח: יומי 0.5%, תוך־יומי 2%; בקריפטו הנפח לא נבדק.
- **פיצול**: מקור גולמי נבדק אחרי יחס פיצול נקי (p/q, q≤4) שמחושב מהנר עצמו — בלי טבלת פיצולים, כדי שלא נכניס הנחה.
- **מקור בלי מרווח מקורי** (2m, 3m, 10m, 3h…): צבירה שלנו של המרווח העדין של אותו מקור לפי הרשת הצפויה, והדלי הראשון החלקי נזרק; מסומן `~1m` וכו׳.
- **הנר החי** לא נכנס (LIVE). **עקביות פנימית (xday)**: הנר היומי מול צבירת כל מרווח תוך־יומי של אותו יום — לסוגים בלי מקור.
- **התפלגויות**: ההפרשים לפי שעה ביום / שנה ולפי גודל (≤2 טיקים, ≤0.1%, ≤1%, >1%) — כדי להפריד בין סינון עסקאות לבין נר שגוי.

## 6. הכלים (`tools/chart-deep/`; הפלט — מחירים ציבוריים — בסקראצ'פד, לא בריפו)
```
node tools/chart-deep/snap.js --file <רשימה> --out <dir> [--ivs 1m,5m] [--pre 0,1] [--rate 30]   # צילום השרתון כמו הטלפון
python3 -I tools/chart-deep/sources.py stocks --syms AAPL,NVDA --out <dir>                    # Webull / Twelve Data / EODHD
python3 -I tools/chart-deep/sources.py crypto --sym BTC-USD --out <dir>   ·   ... fx --out <dir>
node tools/chart-deep/model.js --out <dir>                                                     # מה המסך מציג (chartlib ב־vm)
python3 -I tools/chart-deep/compare.py --out <dir> [--syms ..] [--tfs ..]                     # הפסיקות → <dir>/cmp/<SYM>.json
python3 -I tools/chart-deep/compare.py --selftest                                              # בדיקה עצמית (גם ב־tests/chart-deep.test.js)
node tools/chart-deep/live.js --out <dir> --syms AAPL,SPY,BTC-USD --until 16:20                 # גל 4: הקלטה חיה (מחירים כל 2 שנ׳ + צילומי נרות)
node tools/chart-deep/livecheck.js --out <dir>                                                 # ההקלטה דרך onQuote → applyTick → mergeBars
node tools/chart-deep/kcverify.js --out <dir> --sym AAPL --tfs 1m,3m,…,12M --older 2           # דפדפן אמיתי בסביבת הניסוי: המסך מול המודל
python3 -I tools/chart-deep/ind.py --out <dir>   ·   --selftest                                   # גל 5: המחוונים לפי ההגדרות המקובלות
```
- ההשוואה (`compare.py`) מזהה גם: **קטעי התאמה** (יחס קבוע בין המקור למסך — פיצול, וגם ספין־אוף שאצל Yahoo מותאם ביחס לא נקי: O ‏×1.032 ב־2021, T ‏×1.324 ב־2022, GE ‏×1.04 / ×1.281), **פתיחות לא אמיתיות במקור** (Webull עד ~1991: פתיחה = סגירה — לא נבדקות), **שבועי/חודשי מול צבירת היומי** (`xcal`), **יום תחילת השבוע** (`WD`), **שער ייחוס** של ECB/בנק ישראל בתוך הנר (`FIX`), וימים שחסרים באחד המרווחים (`xday`).
- קצב השרתון: 30 בקשות לדקה (המגבלה 90 ל־IP; ב־80 לדקה Yahoo החזיר לשרת 502 בסדרות). עמוד היסטוריה שנכשל — 2 ניסיונות, ואז נרשם (`endErr`).
- Twelve Data: 8 לדקה. Webull: ~1.2 שנ׳ בין בקשות. EODHD (הדגמה): מעט בקשות ביום — רק לסמלי ההדגמה.
