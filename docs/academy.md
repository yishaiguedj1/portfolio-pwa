# Academy — הספרייה, הקורא והגיבוי

## 16. האקדמיה — ספרייה וקורא (v302, שלב 1 מתוך `תוכנית-אקדמיה-מכתבים.md`)
- **⛔ דף הספר לא מטושטש אף פעם (בקשת המשתמש 28/10/2026)**: גיליונות ותפריטים מעל הקורא (תוכן עניינים, Aa, הדגשות) — עמעום קל בלבד (`html:has(.rd) :is(.lib-veil, …)` ב־`library.css`). טשטוש רק מאחורי בועת אישור/ביטול (`askConfirm`/`askAlert`, אישורי מחיקה וכו׳).

- **מבנה**: `library.js` (ES module) — שכבה `.lib-root` במסך מלא מעל האפליקציה (`no-swipe`), ספרייה (צ׳יפים לפי כותב, "להמשיך לקרוא", רשת כריכות טיפוגרפיות, מיון "לפי שנה · מהחדש" כברירת מחדל), קורא `.rd` עם `<foliate-view>`. "חזור" של המכשיר: רשומות היסטוריה `{lib:1}` (ספרייה) ו־`{lib:2}` (קורא), `onPop` סוגר לפי הרמה — `wireBackNav` של האפליקציה לא מושפע (`snb` מועתק).
- **אחסון**: IndexedDB `snb-library` (`books` = פרטים + מיקום CFI/אחוז/נקרא, `files` = הקובץ) — **לא localStorage** (סעיף 15). הגדרות קריאה ב־`pwa_reader_v1`. מזהה ספר = `dc:identifier` (לא לשנות בקבצים!), אחרת SHA-256 של הקובץ. שנה = מהכותרת ("מכתב באפט 2023") ואז `dc:date`.
- **עיצוב הספר** (`bookCSS`, דרך `renderer.setStyles`): הפונט שלנו עם `font-weight: 100 900` (ברירת המחדל של הקובץ המשתנה = Thin!), עובי 1–5 = 400/470/540/610/680 (1 = לפי ת־קורא), **יישור לתחילת השורה כברירת מחדל** (בעברית ימין, באנגלית שמאל — בקשת המשתמש), ערכות לבן/ספיה/ירוק/שחור. **`html` חייב רקע אטום בצבע הערכה** — רקע שקוף + color-scheme שונה בין ה־iframe לעמוד = מלבן אפור מאחורי הטקסט (נמצא ב־QA). בערכות שאינן לבן — דריסת צבעים קבועים של הקובץ (`#000`/`#333` שנעלמים בכהה).
- **כיוון**: מה־OPF (`page-progression-direction`/שפה) — ספר אנגלי = LTR מלא. **דפדוף רק בהחלקה (v303, בקשת המשתמש)** — המנוע (paginator) גורר ומצמיד; נגיעה בכל מקום = סרגלים בלבד. לא להחזיר נגיעה בשוליים (נגיעה במילה ליד הקצה לתרגום העבירה עמוד). בבדיקות: CDP לא ממלא `screenX` והמנוע נשען עליו — `TouchEvent` עם `screenX` בתוך הפריים.
- **"חזור" בקורא (v303)**: אחד נבלע (`pushState` מחדש + הודעה `rdBackTwice`), שניים תוך `BACK_TWICE_MS` (2 שנ׳) יוצאים; גיליון/בועה פתוחים — "חזור" סוגר אותם; ✕ = `rd.closing` ויוצא מיד.
- **הספרייה המשותפת (v303, שלב 2)**: `ibkr-proxy/api/library.js` + `lib/gauth.js` (בלי תלויות): Firebase ID token מאומת בשרתון (RS256 מול המפתחות של Google, aud/iss של `yishaiguedj1-c786e`), רשימה ב־`LIBRARY_READERS` (מיילים, `*` = כל מחובר; **מיילים רק ב־Vercel, לא בריפו**), Drive דרך חשבון שירות `GDRIVE_SA_KEY` (JSON או base64) לתיקייה `LIBRARY_FOLDER_ID` + תת־תיקייה אחת; קובץ נשלח רק אם ההורה בתיקייה. `LIBRARY_FOLDER_ID` מקבל גם קישור מלא; `op:'health'` = בדיקת הגדרה בלי התחברות (רק מספר המכתבים); "not_configured" מיד אחרי שמירת משתנים = לרוב הפריסה עוד רצה. באפליקציה `syncDrive` בכל כניסה (4 הורדות במקביל + "n מתוך t"): `driveSyncPlan` (טהורה) — הורדה לפי md5, הסרה של מה שנמחק, ספר מיובא ידנית נשאר. בלי הגדרה/התחברות/רשת — שקט.
- **דף מכתב + סנכרון (v305, שלב 3)**: כריכה → דף מכתב (`renderBook`, לפי מוקאפ שלב 0: נתונים, CTA, "בקצרה" מ־`dc:description`, תוכן עניינים מקופל → פרק). ניווט פנימי = `goView(v)` + `lv` ברשומת ההיסטוריה (`onPop` משחזר). נתוני מכתב בייבוא `bookExtras` (`meta:2`; ישן — משלים בפתיחת הדף). **התקדמות והגדרות בענן**: שדה `lib` במסמך `users/{uid}` עם `merge` (`p` לכל ספר לפי `cloudKey`, `s` הגדרות; `mergeProgress` — הכי עדכני מנצח). **לא לכתוב `lib` דרך cloud.js ולא לגעת ב־`db` מ־library.js.** לחיצה ארוכה = הסרה רק לספר ידני (`src!=='drive'`).
- **הדגשות/הערות/סימניות/ציטוט (v306, שלב 4)**: ב־`rec.ann` (`{id,c,x,k,n,b,ch,f,u,d}`; מחיקה = מצבה `d:1`), ענן `lib.a[cloudKey][id]` עם merge, `mergeAnn` לפי `u`. ציור דרך המנוע (`addAnnotation` ← `draw-annotation` ← `Overlayer.highlight`, צבעים `HL_COLORS`); נגיעה בהדגשה = `show-annotation` (`rd.annTap` מונע החלפת סרגלים). בועה אחת `buildPop` לסימון חדש ולקיים. סימנייה = CFI בטווח הגלוי (`pageHasBookmark`). כרטיס ציטוט = קנבס 1080×1350 + `navigator.share`. "מה למדתי" = `goView({notes:1})` / `renderNotes`. בבדיקות: לא `fetch` ל־blob (CSP) — לצלם רכיב.
- **שכבת האקדמיה (v307, שלב 5)**: ניתוח לכל מכתב = `op:'insight'` ב־`api/library.js` → `lib/epubtext.js` (טקסט מ־EPUB בלי תלויות) → `lib/insight.js` (Gemini, JSON בעברית: summary/ideas/lens/terms/question; `lens.thinker` רק מתוך `THINKERS`; מבוסס טקסט בלבד). מטמון בשרתון id|md5; באפליקציה `rec.ins` (**לא בענן** — גודל מסמך המשתמש). תוכן קבוע ב־`academy-data.js` (THINKERS/GLOSSARY/TRACKS) — עובדות מוכרות בלבד, ציטוט רק כשמיוחס בבירור; מסלול = שנות מכתבי באפט (`trackLetter`: מכתב לבעלי המניות קודם למכתב שותפות), שלב בלי מכתב לא מוצג. מונח בבועת הסימון = `glossaryMatch`. `maxDuration` של library.js = 60.
- **חיפוש בספרייה (v308)**: `.lib-search` מתחת לכותרת. סינון ודירוג **במקום** (`applySearch` על `data-q`/`data-i` — לא `renderHome`, אחרת המקלדת נסגרת). סלחני: `editDist` (Damerau, 0/1/2 לפי אורך), שלד בלי א/ו/י/ה + סופיות (`fold`/`skel`), מקלדת הפוכה (`swapLayout`), כינויים (`ALIASES`). שנים — רק מדויקת או ספרות שהתחלפו (לא 1986 ל־1987). יש התאמה מדויקת (≥2.5) → בלי "קרובים".
- **חיפוש בתוך המכתבים + ניהול (v309, שלב 6)**: אינדקס ב־IndexedDB `snb-library` **גרסה 2** (מאגר `text`; שינוי סכמה = גרסה חדשה + `onupgradeneeded` שלא מוחק), נבנה ברקע (`indexAll`, לא בזמן קריאה). `foldMap`/`ftFind`/`snippet` טהורות; קפיצה = `openReader(id,{find:{q,sec,k}})` → `view.search` לפרק. ניהול: `op:'me'|'readers'|'addReader'|'removeReader'|'refresh'`; מנהל = `LIBRARY_ADMINS` או המייל הראשון ב־`LIBRARY_READERS`; קוראים נוספים ב־Firestore `academy/config` דרך חשבון השירות (תפקיד "Cloud Datastore User" בפרויקט ה־Firebase), **רשימה חתומה HMAC** — לא לוותר על החתימה. בבדיקות: לא `waitForFunction` עם Promise.
- **ליטוש (v310, שלב 8)**: חיפוש בטקסט — סינון מוקדם על `foldQuick` שמור לכל פרק (`sec._f`), `foldMap` רק לפרק עם ניקוד; לא להחזיר קיפול תו־אחר־תו לכל שאילתה (1.2–5.7 שנ׳ ב־84 מכתבים). `ftCache` — רק דרך משתנה מקומי (`indexBook` מאפס באמצע). **אופליין**: `LIB_SHELL` ב־sw.js — קובץ חדש שהספרייה מייבאת חייב להיכנס לשם (הבדיקה עוקבת אחרי הייבואים ונכשלת). נגישות: כל גיליון דרך `sheet()` (דיאלוג + החזרת פוקוס), Escape על `document` → `onEscape`. מדידה: Playwright עם 84 מכתבים כ־`File` עם שם (Blob בלי שם לא נפתח במנוע) + CPU×4, ו־`serviceWorkers:'block'` כשמחליפים קבצים ב־route.
- **כריכה מהקובץ (v314)**: בייבוא `coverThumb` (`book.getCover` → JPEG עד 480px) נשמר ב־`rec.cover`/`rec.coverRatio` (IndexedDB, לא localStorage); `cover(b)` מציג אותה (`.lib-cover.img`), אחרת הכריכה הטיפוגרפית. **מכתב שעבר לקובץ אחר באותו `dc:identifier`** (תיקייה חדשה/העלאה מחדש): ב־`syncDrive` מוחקים רשומה רק אם `driveId` שלה עדיין של הקובץ שנעלם — אחרת המחיקה הייתה מוחקת את הספר שזה עתה ירד (`library-v314.test`). שני קבצים עם אותו מזהה בתיקיית הספרייה = הורדה חוזרת בכל כניסה — להשאיר עותק אחד.
- **v315**: (1) **השלמת כריכה** לספרים שכבר בטלפון (`backfillCovers` בכל כניסה, לפי `coverV` — ספר שהקובץ שלו לא השתנה לא יורד שוב, אז בלי זה לא תהיה לו כריכה). (2) **רענון בזמן שהספרייה פתוחה** → חוזרים אליה (`app.js` קורא `history.state.lib` באתחול → `openLibrary({restore})`: בלי pushState, `ui.view = lv`, ב־`lib:2` פותח את הספר `book`; גלילה לכל דף ב־`sessionStorage` `pwa_libscroll_v1`). - **v316 — עריכת ספר ברמת Calibre**: לחיצה ארוכה על ספר = `wireHold` → `showItemActions` של המניות (עט + X, מעל הספר בצד שמאל; `html.lib-open .item-acts.floating` z-index 1002 מעל שכבת הספרייה). **בלי תפריט "הורדת תמונה"** (`contextmenu` נחסם על כריכות + `-webkit-touch-callout:none`). עריכה = `goView({edit:id})` → `renderEdit`: 12 שדות (`EDIT_FIELDS`, ממולאים מהקובץ ב־`fileDefaults`), כריכה מהטלפון/מהרשת (`coverFromBlob`, JPEG ≤480px), נשמר ב־`rec.edit` + `applyEdit` (טהורה) — **שורד עדכון קובץ** (`importFiles` מחיל מחדש `edit`/`coverCustom`/`hidden`); "שחזור הפרטים מהקובץ" מבטל. מחיקה: ספר ידני — נמחק; מכתב Drive — **מוסתר** (`hidden`, הקובץ נמחק מהטלפון, `driveSyncPlan` לא מוריד שוב) + "מוסתרים (n)" לשחזור. **משיכת פרטים**: `ibkr-proxy/api/bookmeta.js` + `lib/bookmeta.js` — 4 מאגרים במקביל: **הספרייה הלאומית** (SRU של Alma `972NNL_INST`, MARC — המקור הרשמי לעברית, בלי מפתח, בלי כריכות), Google Books (`GOOGLE_BOOKS_KEY` ב־Vercel — **הוגדר 04/10/2026**, מוגבל ל־Books API; בלי מפתח 429 גם מ־Vercel; אבחון: `diag.googleKey` + הודעת השגיאה ב־`status`), Open Library, Apple Books (iTunes Search); דירוג: עברית → הספרייה הלאומית קודם (משקל ×6) + `alma.language=heb` (הקטלוג לא ממוין לפי רלוונטיות — בלי זה מהדורות זרות תופסות את הראש), 20 רשומות ודירוג **לפני** חיתוך ל־6 מכל מקור. `mergeByIsbn` (לפי ת־קורא) — כל רשומה מקבלת כריכה/תקציר/עמודים ממקור אחר באותו ISBN; לספר עברי — בקשה ל־Google לפי ה־ISBN של שתי ההתאמות הראשונות בקטלוג (`enrich`, לא מוצגת לבד). Amazon/Goodreads — אין ממשק רשמי פתוח. QA: Playwright עם `hasTouch` + CDP touch (לחיצה ארוכה), `ignoreHTTPSErrors` (פרוקסי הסביבה).
- **v350 — משיכה מצד המסך ("חזור" של Chrome באנדרואיד)**: Chrome מציג **צילום של הרשומה שחוזרים אליה**, שצולם כשעזבו אותה. לכן: (1) לא לדחוף שתי רשומות ברצף לפני שהמסך שאליו הן שייכות צויר — רשומת הקורא נדחפת אחרי הציור הראשון (`rd.armed`); **v351: רק כשהמסך מוצג במלואו** (`readerArm`: בלי loading, אחרי אנימציות הכניסה, +350ms — צילום באמצע `rdIn` הראה את הספרייה דהויה). משיכה **משמאל** = Chrome מחליק צילום; **מימין** = בלי צילום — לבדוק תמיד את שני הצדדים, אחרת הצילום של השומר = הדף הקודם ו"חזור" מבזיק אותו; (2) `popstate` עם `hasUAVisualTransition` = Chrome כבר הנפיש → בלי אנימציה משלנו (`closeReader({instant})`, `navigateTo('none')`, `closeLibrary(true)`). "חזור" מהעמוד הראשי של הספרייה → סקירה (`appToOverview` + מעבר בפתיחה מטאב ראשי). אי אפשר לבדוק את אנימציית Chrome ב־Playwright — אישור בטלפון. **v352 — כשיש `CloseWatcher` (Chrome 120+) הקורא לא משתמש בהיסטוריה ל"חזור"**: רשומה אחת, `readerWatch`/`readerCloseRequest` (בקשת סגירה = בלי ניווט = בלי צילום/קפיצה); מאזין חדש אחרי כל בקשה, נגיעה מחדשת מאזין חסר, `closeReader` משחרר. השומר של v350/v351 — רק לדפדפן בלי תמיכה. **שכבה חדשה במסך מלא שצריכה "חזור" בלי לצאת — עדיף CloseWatcher על רשומות היסטוריה.**
- **v349 — "חזור"/✕ בקורא (באג חמור)**: (1) **אסור `iframe.src = url` על מסגרת שכבר נטענה** — כל טעינה = רשומה בהיסטוריה המשותפת, ו"חזור" של המכשיר הולך אחורה בתוך מסגרת נסתרת ולא עושה כלום (`frameGo` ב־pagecurl = `location.replace`). לבדוק `history.length` לפני/אחרי דפדוף בין פרקים. (2) **יציאה מהקורא בלי ספירת רשומות**: `readerExit` סוגר מיד, ורשומות קורא יתומות מדולגות (`skipStale`/`readerLeaveHistory`, back אחד בכל פעם; back בתוך/מיד אחרי popstate לא תמיד מבוצע).
