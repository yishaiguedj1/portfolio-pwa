## 18. סטודיו התרגום (v354–v355, שלבים 1–2 מתוך התוכנית שאושרה)
- **מה זה**: תרגום סרטונים בתוך האפליקציה — Claude של המשתמש (Routine בענן, במכסת המנוי שלו) מתמלל, מתרגם וצורב; האפליקציה רק מפעילה ומציגה. התוכנית המלאה (9 שלבים, מצבי תרגום, "מגדל הפיקוח", עלויות) — בארטיפקט התוכנית; שלב 0 (ספייק) — המלצה להמשיך.
- **מבנה**: `studio.js` + `studio.css`, נטענים רק בלחיצה על `#menuStudioBtn` (`import('./studio.js')` → `openStudio()`), כמו הספרייה. שכבה `.st-root` (z-index 900, אטומה, `no-swipe`, `html.studio-open`); לולאת המחירים מושהית (`liveCanTick`). **`studio.js` לא פונה לרשת בעצמו** — הכל דרך `studionet.js` (נאכף בבדיקה).
- **אחסון**: `pwa_studio_v1` = `{settings, drafts, jobs, conn, drive}` (ב־`ACCOUNT_KEYS`). טיוטה = שם/גודל/סוג הקובץ + הבחירות — **אף פעם לא הקובץ**. עבודה (`normJob`) = הפרטים, מצב ההעלאה (כתובות ההעלאה של Drive — רק `www.googleapis.com/upload`, כמה עלה) והמצב האחרון מהשרתון; מהחיבור — רק הרמז (`trig_…ABCD`). כל קריאה עוברת `normStore`. ידית לקובץ (File System Access, כשיש `showOpenFilePicker` — גם ב־Chrome לאנדרואיד) ב־IndexedDB `snb-studio` — המשך אחרי רענון בלי לבחור שוב.
- **"חזור" (לקח v350–v352 של הקורא)**: עם CloseWatcher (Chrome 120+) — **רשומה אחת** לסטודיו (`{studio:1, sv, sp}`, מתעדכנת ב־`replaceState` לרענון), הדפים במחסנית בזיכרון (`stack`), ו"חזור" = בקשת סגירה (`watch`/`closeRequest`): דף אחורה באנימציה שלנו, חלון אישור פתוח — רק הוא (לחיצה על הביטול שלו), בדף הבית — יציאה ב־back תוכנתי. כך Chrome לא מחליק צילום ישן של הדף הקודם (בטופס — עם הבחירות הישנות). מאזין אחד בכל רגע; חדש אחרי כל בקשה, בכל ציור אם חסר, ובנגיעה. Escape משלנו רק בלי CloseWatcher. בלי תמיכה — רשומה לכל דף דרך `cleanState` (שומר `snb`), ובלי אנימציה כפולה כש־`hasUAVisualTransition`. בשני המצבים: pushState/replaceState/back רק דרך `afterBack`; `onPop` מתעלם מ־`modalPop`/`navSkip`; היציאה → הסקירה (כמו בספרייה: מטאב ראשי app.js עובר אליה כבר בפתיחה, מעמוד משנה — `appToOverview` ביציאה). רענון: `index.html` מוריד וילון (`h.studio` → `studio-open`; שינוי בסקריפט = hash ב־CSP), `app.js` → `openStudio({restore})`, ובמצב CloseWatcher `chainFor` בונה את המסלול (הטופס בזיכרון — דף שפות של טופס חוזר לטופס חדש). QA ל"חזור": Escape = בקשת סגירה בדסקטופ; את מצב ההיסטוריה בודקים עם `delete window.CloseWatcher` + CDP `navigateToHistoryEntry`. **29/10/2026 (2.82.8)**: `go` לדף שכבר מוצג (אותו `view`+`param`) רק מצייר — בלי מקום נוסף במחסנית/רשומה; `back` מדלג על עותקים רצופים; `goJobLink` לא דוחף עבודה שכבר פתוחה (פתיחה מההתראה "התרגום מוכן" כשהעבודה פתוחה נתנה "חזור" ראשון שמנפיש מעבודה לאותה עבודה).
