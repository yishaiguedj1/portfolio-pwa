### רצועה קבועה בקובייה — רקע בגודל השכבה (29/10/2026)

### sticky בהעתק חלקי — האב צריך את הגובה המקורי (29/10/2026, הניתוח)
אלמנט `position: sticky` לא יוצא מתחתית האב שלו. העתק קצוץ (`cubeHold` מעתיק רק את מה שמעל קו מסוים) מקצר את האב, והלשוניות הדביקות נדחפו למעלה ב־3.7px עד הנחיתה. הפתרון: אב שמועתק חלקית מקבל `box-sizing: border-box` ו־`min-height` בגובה המקורי. ובגלאים: אנימציה שמונעת מגלילה (`timeline !== document.timeline`) לא מקפיאים ולא מסיימים.
