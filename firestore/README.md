# כללי הגישה ל־Firestore

`firestore.rules` קובע מה הטלפון רשאי לעשות במסד הנתונים:
- **מותר:** כל משתמש קורא וכותב רק את המסמך שלו, `users/{uid}`. שם נמצאים התיק, ההגדרות והתקדמות הקריאה.
- **אסור לכולם:** כל השאר — עבודות הסטודיו, הכספות המוצפנות, השרתים והמטמונים. רק השרתון ניגש אליהם, דרך חשבון השירות, שלא כפוף לכללים האלה.

## העלאה (פעם אחת, ואחרי כל שינוי בקובץ)

1. Firebase Console ← הפרויקט `yishaiguedj1-c786e` ← Firestore Database ← Rules.
2. מוחקים את מה שיש שם ומדביקים את כל `firestore.rules`.
3. Publish. הכללים פעילים תוך דקה.

הכללים בקובץ הזה **לא מתפרסים לבד** — מה שבקונסולה הוא מה שפועל בפועל. לפני העלאה בודקים שהבדיקות ירוקות.

## בדיקות

`rules.test.mjs` רץ מול האמולטור הרשמי של Firebase, בלי הפרויקט האמיתי ובלי נתונים אמיתיים. ב־CI זה ה־job `firestore-rules` ב־`test.yml`. מקומית (דורש Java 21):

```
cd firestore && npm ci && npm test
```
